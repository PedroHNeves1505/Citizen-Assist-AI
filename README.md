# CitizenTech AI Assistant — Assistente de Informação para Pessoas Idosas

## Global Solution 2026.2 — FIAP

### Descrição do projeto

O **CitizenTech AI Assistant** é um protótipo de assistente inteligente desenvolvido para facilitar o acesso a informações de serviços e direitos voltados à população idosa.

O projeto utiliza Inteligência Artificial Generativa e a técnica RAG (Retrieval-Augmented Generation) para consultar uma base documental antes de gerar suas respostas. O objetivo é reduzir respostas incorretas ou inventadas, permitindo que o assistente responda com base nas informações disponíveis nos documentos.

A solução foi pensada para tornar o acesso à informação mais simples, claro e acessível, especialmente para pessoas idosas que podem ter dificuldades para localizar informações em documentos extensos ou em diferentes canais de atendimento.
